# MAGICA Brand Assets Repository

This directory contains the canonical visual identity and branding assets for **MAGICA** (*Powered by Oh Magic View*).

---

## Mandatory Brand Integrity Requirements

1. **Original Artwork Preservation**:
   - The supplied **MAGICA Tiger artwork** is the core identity anchor of the brand.
   - It represents the spiritual, energetic, and majestic Himalayan essence of Kasol and DJ Pratap (KingUrjapati).
   - **DO NOT** replace the original tiger artwork with an unrelated, stock, or cartoon tiger.
   - **DO NOT** invent alternate official logos or disrupt the brand hierarchy.

2. **Required Files to place in this directory**:
   - `magica-tiger-original.png` — High-resolution master raster artwork of the MAGICA tiger.
   - `magica-tiger-vector.svg` — Scalable vector rendition of the MAGICA tiger mark.
   - `magica-wordmark.svg` — Official MAGICA typography wordmark.
   - `magica-lockup-horizontal.svg` — Combined mark + wordmark horizontal lockup.
   - `magica-lockup-vertical.svg` — Combined mark + wordmark vertical lockup.
   - `powered-by-oh-magic-view.svg` — Endorsement badge.
   - `favicon.ico` / `apple-touch-icon.png` — Web and mobile icon assets.

3. **Status Note (Phase 0 Audit)**:
   - At project initialization, external image files were not present in the repository root.
   - As specified in the master instructions, this placeholder documentation explicitly registers the requirement for the original high-resolution MAGICA tiger artwork to be provided and placed here prior to Phase 1 brand styling.
